# 界面重设计说明 ·「夜航」

本副本的前端视觉与交互结构已从零重做；业务逻辑、接口、权限校验、流程规则和数据均未改动，193 项自动测试全部通过。

## 设计语言

| 维度 | 做法 |
| --- | --- |
| 基调 | 深墨色侧栏（带星点光晕）+ 暖中性纸面画布，辨识度来自明暗对比而非大面积品牌色 |
| 色彩 | 主按钮用墨色；唯一标志色「星河蓝」只用于焦点、选中和链接；品牌渐变只出现在标志、登录页和首页横幅 |
| 状态 | 统一为「色点 + 浅底」药丸：待开始灰、评审紫、开发蓝、测试琥珀、完成绿（勾）、终止灰 |
| 数字 | 指标、日期、编号用等宽字形，便于纵向对齐比较 |
| 主题 | 浅色 / 深色两套令牌，跟随系统，顶栏可手动切换并记住选择 |

## 结构变化

- **侧栏**：项目切换器做成带项目色块的卡片（底层仍是原生下拉，键盘可用）；需求池、研发任务显示实时数量。
- **团队工作台**：问候横幅 + 一体化指标条 + 项目卡片网格 + 右侧常驻「我的待办」。
- **项目概览**：环形完成率、状态分布条、横向里程碑轨道（已过节点实心）。
- **需求池 / 任务**：表格加头像与编号标签；看板按阶段着色，逾期卡片左侧红边。
- **详情与编辑**：从居中弹窗改为右侧抽屉，保留列表上下文；确认类操作用居中小窗，文档预览与版本对照用宽窗。
- **登录页**：左侧星空叙事面板展示「沉淀需求 → 拆解任务 → 按期交付」三步。
- **手机端**：侧栏变为抽屉，指标两列，表格横向滚动，页面无横向溢出。
