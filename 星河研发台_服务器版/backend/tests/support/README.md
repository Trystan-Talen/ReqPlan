# 隔离浏览器验收

在项目目录使用 Node.js（运行时）24.15 以上、25 以下版本运行：

```sh
node backend/tests/support/browser-server.mjs
```

打开终端输出的本地地址。测试管理员为 `quality-admin`，观察者为 `quality-viewer`，密码见终端输出。观察者仅能读取指定测试项目。

服务只监听本机，使用项目自带的脱敏示例数据和内存数据库，不读取或修改工作区业务数据库。停止进程后，本次测试产生的账号和修改全部消失。此脚本仅用于本地验收，不用于部署。

建议验收步骤：

1. 管理员登录，检查全局排期的项目/人员视图，以及任务的列表/看板/分组视图。
2. 编辑并保存一条示例任务，刷新页面，确认保存结果保留。
3. 退出并登录观察者，刷新页面，确认无管理入口、无编辑操作。
4. 在宽度 1440 和 375 下检查浅色/深色主题，并打开 `/design-system.html`（样式指南）。
5. 检查浏览器控制台无错误，结束后停止服务。

自动化回归测试另见 `frontend-contract.test.mjs`（刷新顺序、会话隔离、视图分支）、`performance-contract.test.mjs`（查询范围与通知结果）、`runtime-package.test.mjs`（运行包依赖完整性）。全套测试从项目目录运行 `npm test`（执行测试）。
