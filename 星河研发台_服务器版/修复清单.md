# 项目评估问题修复清单

当前维护对象是本目录的服务器版。桌面原项目与旧单文件页面是历史版本，不能把它们的实现现状当作服务器版现状。操作入口与部署步骤见 [使用说明](README.md)，验收范围见 [验收说明](验收说明.md)。

| 问题 | 本次处理 | 验证重点 |
| --- | --- | --- |
| 正式目录与旧页面混淆 | 明确服务器版目录和启动入口，交付说明区分当前与历史记录 | 从启动器访问服务，核对当前版本 |
| 批量拆分任务能力遗漏 | 恢复整批校验、事务提交、重复提交去重、失败保留草稿 | 一行错误时整批不写；重复提交不增加任务 |
| 附件没有版本链 | 按同需求、同名、同类型归为版本链，旧地址继续可下载 | 历史字节不变、并发上传版本唯一 |
| 原附件历史未迁入 | 独立补录脚本默认预检，执行前备份，按来源和内容去重 | 原版本库不修改，重复补录不重复插入 |
| 正式文档长文难以阅读 | 增加目录、标题锚点、嵌套列表、表格、代码及引用；原始网页内容转义 | 危险链接禁用、目录不干扰页面路由、超长内容明确提示 |
| 原需求历史未展示 | 读取并合并原历史与现代审计 | 正确需求归属、顺序、权限及内容转义 |
| 修改前后内容不易追溯 | 详情展示字段差异，附件支持历史文本对照 | 旧值、新值、作者及时间可核对 |
| 改期基线字段不一致 | 统一读取新旧字段，展示原计划、现计划、偏移与改期次数 | 缺失日期不编造，旧字段仍可读 |
| 前后端流程规则分叉 | 共享纯规则模块，界面提示和接口校验引用同一来源 | 角色、阶段、验收与终止条件一致 |
| 批量改期缺少预览和冲突保护 | 提交前预览差异与项目目标日期警告 | 任一过期版本使整批回滚 |
| 缺少需求与任务依赖 | 前置需求和任务选择、环路检查与开工条件校验 | 未完成、跨项目及循环依赖拒绝 |
| 个人待办仅显示少量摘要 | 增加个人任务、参与需求与待验收入口 | 仅汇总本人有权访问的有效项目 |
| 交付与验收缺提醒 | 站内逾期、近期到期、阻塞及验收提醒，可标记已读 | 刷新更新，权限收回后不能继续读取 |
| 缺跨项目风险与趋势 | 显示未完成、逾期、未排期及八周变化 | 统计口径明确，缺失日期单列 |
| 缺自动备份 | 后台定时、失败重试、保留份数、可选第二目录及管理员状态 | 不覆盖、失败不停止业务、日志脱敏 |
| 缺恢复验证 | 临时副本检查结构、约束、数量及事务 | 原库不替换，支持旧结构升级演练 |
| 测试建议可能覆盖业务库 | 测试仅用内存或临时目录；持续集成只执行语法与测试，旧重填脚本增加临时目录限制 | 不调用重填数据，不读取实际凭证 |
| 缺持续集成配置 | 固定运行环境版本，自动定位项目并执行完整检查 | 远程执行仍须连接实际仓库 |

## 保持的使用约定

- 密码最低 6 个字符，当前本机管理员仍为 `admin`（管理员账号）。
- 本机网页与接口继续动态分配端口，不占用固定端口。
- 原编号、业务正文、任务、关联与附件内容保留；不使用演示数据替换。
- 只读角色、项目成员、里程碑、密码散列、会话到期与登录限流沿用并参与回归验证。

## 需要实际环境落实的项目

- 第二备份目录需要运维挂载受控设备并验证恢复；当前配置不等于异地备份已完成。
- 持续集成需要真实远程仓库；容器、域名、证书、容量测试需要目标服务器。
- 旧模型凭证是否撤销仍未确认，代码修复不能替代服务商端撤销。
- 当前提供站内提醒；邮件、外部消息推送、单点登录和模型分析没有配置。功能点层继续后排。
