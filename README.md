# 星河研发台 · 正式入口

双击本目录“启动正式版.command（启动文件）”，或运行 `npm start`（启动服务）。网页和接口自动选择空闲端口。

当前维护源码位于 [星河研发台_服务器版](星河研发台_服务器版/README.md)，业务库位于该目录下的 `backend/var/xinghe.sqlite`（数据库文件）。管理员沿用 `admin`（管理员账号）和原密码。

[逐项修复清单](星河研发台_服务器版/修复清单.md) · [当前验收说明](星河研发台_服务器版/验收说明.md)

原 `server.js`（旧服务文件）、`public`（旧界面目录）、原数据库和静态页面仅用于回溯；本入口启动服务器版。旧页面修改不会同步到新服务。

命令行工具保留在 `CLI/xinghe-cli`（命令行工具目录）；测试会自动定位相邻的服务器版。

修改前的入口文件已存入 `.maintenance-backup-20260916`（维护备份目录）；其中可能包含旧配置，不应发布。

本次已通过服务器与命令行工具联合 193 项测试；服务地址由启动器动态分配，当前状态见服务器版的本机运行状态文件。
